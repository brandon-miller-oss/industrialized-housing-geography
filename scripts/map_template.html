Survey-Eligible Modular Factories

U.S. factories that build volumetric residential modules to state code and are not HUD-code only (RV/park models, tiny homes on wheels and kits excluded; duplexes count as single-family) · Geography of Industrialized Housing, CHRIS, University of Denver · · Back to the full database

Layers

Each dot is a factory at its ZIP code. Single-family and Multifamily each include every factory that builds that type, so a factory that builds both is counted in both. Both SF and MF is the overlap. Factories that build both show purple whenever both lists, or the overlap layer, are on; with only one list on they take that list's color. Numbered dots hold several factories at one ZIP. Scroll or use + / − to zoom, drag to pan.
